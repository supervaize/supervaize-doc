# Work with cases

A case is one unit of work inside a job, for example one person to contact or one document to produce. Your agent creates cases while the job runs. You cannot create a case in Studio.

You use cases to follow progress, answer an agent that waits for you, and collect deliverables.

## Case statuses

| Status | Where you see it |
| --- | --- |
| **Stopped** | Not started. The board shows it in the **Todo** column. |
| **Starting** | The board shows it in **In Progress**. |
| **In progress** | The board shows it in **In Progress**. |
| **Cancelling** | The board shows it in **In Progress**. |
| **Awaiting** | The board shows it in **Waiting for Input**. |
| **Completed** | The board shows it in **Success**. |
| **Failed** | The board shows it in **Anomaly**. |
| **Cancelled** | The board shows it in **Anomaly**. |

For the board, the list and the calendar, see [Navigate a job](./job-navigation).

## The case page

The page title shows the case name, its tags and its status. Two buttons sit next to the status.

| Button | What it does |
| --- | --- |
| **Case Rating** | Opens the rating of this case. |
| **Case comments** | Opens the comments of this case. |

Two links at the top lead back: **Back to Job** and **All cases of this job**.

| Area | What you find there |
| --- | --- |
| **Case Information** | **Agent**, **Mission**, **Job**, **Created**, **Finished** and **Type**. The first three are links. |
| **Case Result** | **Duration**, **Cost** and the number of **Steps**. |
| **Contact Data** | Data that the agent publishes about the case. It shows only when the agent sends some. |
| Step timeline | The steps of the case, in order. |

:::note[Ratings]
Case Rating is available when the mission rates its cases. See [Ratings](./rating-analytics).
:::

## Answer an agent

An agent can stop a case to ask for a human answer. The case gets the status **Awaiting**.

1. Open the case.
2. Find the step that waits for you in the timeline.
3. Fill in the form of the step.
4. Select **Submit**.

The agent can change the label of this button. The case then continues.

A final step that carries files reads **Deliverables**. A step without files reads **Final**.

For the developer side, see [Human in the loop](/docs/supervaizer-controller/human-in-the-loop).

## Actions Panel

Select **Actions Panel** in the sidebar to see what needs you across your missions. Each section shows a count.

| Section | What it shows |
| --- | --- |
| **Needs your input** | Cases in **Awaiting** status. |
| **Anomalies** | Cases that failed or were cancelled. |
| **Completed** | Completed cases, grouped by job, with the total cost. |
| **In progress** | Cases that are running. |

Each card has a **Details** button. A card in **Needs your input** has **Skip**. A card in **Anomalies** has **Dismiss**.

**Skipped** and **Dismissed** lists hold the cards that you hid. Select **Restore** to bring a card back.

:::tip[Start with Needs your input]
These cases are blocked until someone answers.
:::

## Case lists

Two lists show cases.

| List | How to open it |
| --- | --- |
| Cases of a job | In the **Cases** section of a job, select **View all →**. |
| **All Cases** | Open it from a card on the Dashboard. It has no sidebar item. |

### Filters

| Filter | Cases of a job | All Cases |
| --- | --- | --- |
| Search by case name or ID | Yes | Yes |
| **Status** | Yes | Yes |
| **Agent** | Yes | No |
| **Lane** | Yes | No |
| **Has deliverables** | Yes | Yes |
| Tag filter | Yes | Yes |

**Status** offers **Completed**, **Awaiting**, **In Progress**, **Failed** and **Stopped**.

Click **Tags** to open a searchable list of the tags. Select a tag to show it. Select **Exclude** on a tag to hide every case that has it. The filter shows your picks as chips, such as "Tag is any of billing, urgent" and "Tag is not review". Click **is any of** to switch to **is all of**.

### Export

| Button | What you get |
| --- | --- |
| **Export CSV** | A CSV file of the listed cases. You pick the columns first. Cases of a job only. |
| **Full export** | A CSV file with all fields, or a Google Sheet that Studio keeps up to date. |
| **Download deliverables** | A zip file of the deliverables of the cases you tick. |

**Download deliverables** is off when no listed case has deliverables.

:::note[Google Sheets]
A Google Sheet keeps the status, agent and mission filters only. It does not keep search, deliverables or tag filters. Use the CSV for those.
:::
