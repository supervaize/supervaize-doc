# Create a job

A job is one run of one agent inside a [mission](./mission-management.mdx). You give the agent its parameters, set optional limits, and start. The agent then creates cases as it works.

- **The agent defines the form.** Each agent asks for its own parameters, so two agents show two different forms.
- **Your answers are saved as a draft.** Leave the page and come back: the form is as you left it.
- **Limits are optional.** Cap the number of cases, the duration or the cost before you start.

## Start a job in three steps

Try the flow here first. The buttons work.

<JobCreateDemo />

### 1. Click New Job

Open the mission and click **New Job** at the top right.

- **One agent on the mission**: Studio opens the job form directly.
- **Several agents**: pick the agent, then click **Continue**.

You can also open the agent's **Manage** menu on the mission page and choose **Start Job**.

### 2. Fill in the parameters

The page has two sides.

**Left: Job Parameters.** The form served by the agent. Fields can appear or disappear depending on your earlier answers, and some lists are loaded live from the agent. Studio saves your answers as you type.

**Right: the job settings.**

| Setting | What it does | Default |
| --- | --- | --- |
| **Name** | The job's name. **Generate** writes a unique one from the agent name and the current time. | _Mission name - Agent name_ |
| **Description** | A free note about this run | Empty |
| **Max Cases** | Stop after this many cases | No limit |
| **Max Duration (seconds)** | Stop after this long | 36000 (10 hours) |
| **Max Cost (USD)** | Stop once this amount is spent | No limit |
| **Stop on Warning** | Stop the job on the first warning | Off |
| **Stop on Error** | Stop the job on the first error | On |

The limits are under **Execution Limits** and the two stop switches under **Conditions**. Both are collapsed until you click them.

### 3. Start

Click the start button at the bottom right. It reads **Start Job** unless the agent gives it another label. Studio opens the job page; next, [find your way around it](./job-navigation.mdx).

:::warning[The start button stays disabled while the form is not ready]
It is disabled while the agent's lists are still loading, and when the agent's form could not be loaded. If it stays disabled, check that the agent's server is online.
:::

## Other ways to start a job

### Dialog Mode

When your workspace has the dialog feature and the mission has a dialog model set, a **Form Mode / Dialog Mode** switch appears above the parameters. In **Dialog Mode** you answer questions in a chat, and the collected values fill the same form. If something required is still missing, Studio brings you back to the form with your answers kept.

### LLM agents

For an agent that runs on an LLM, **New Job** opens a **Job Builder Conversation** instead of a form. You describe what you want, the **Job Definition** panel fills in as you talk, and **Confirm & Create Job** becomes available once it is complete.

:::info[Created, not started]
A job built this way is created but does not start by itself. Open it and click **Start**.
:::

### From Claude or ChatGPT

With the [Supervaize MCP connector](../mcp-connector/install.mdx) and the **Write** permission, ask:

> Start a new job for Aidan in the Onboarding Check-ins mission.

The assistant first shows a preview of what it would create. Nothing starts until you confirm.

## Troubleshooting

| Symptom | Cause | Fix |
| --- | --- | --- |
| No **New Job** button | You are not allowed to run jobs in this mission | Ask the mission manager to add you |
| "No authorized agents are available for this mission" | The agent's access to this workspace was not accepted | A workspace admin or agent manager accepts the agent's workspace authorization |
| "Agent contract is not available" | The agent has not registered a job form with Studio | Update the agent's Supervaizer controller and register it again |
| "Failed to load ... from the agent" | The agent could not return one of its lists | Check that the agent's server is online, then reload |
| "Could not save draft changes" | The draft could not be saved | Keep going: starting the job still uses what is on screen |
