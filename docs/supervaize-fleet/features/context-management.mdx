# Manage context

Context is a library of items. An item is a file, a piece of text, a URL or a connection. The Studio page describes them as items available to your runtime tools.

An item has a **Scope**. A **Workspace** item belongs to the whole workspace. A **Mission** item belongs to one mission.

Context shows only when it is enabled for your workspace. The context pages need an active subscription.

## Open the library

Select **Advanced**, then **Context**. The page title is **Context Items**.

Every member of the workspace can read the list and open the detail panel of an item. Only workspace admins can add, edit and delete items.

| Column | What it shows |
| --- | --- |
| **Name** | The name of the item. |
| **Type** | **File**, **Text**, **URL** or **Connection**. |
| **Scope** | **Workspace** or **Mission**. |
| **Status** | The state of the item. |
| **Size** | The size of the item. |
| **Parent** | The object that the item belongs to. |
| **Created** | The creation date. |

### Status values

| Status | Meaning |
| --- | --- |
| **Active** | The item is ready. |
| **Processing** | Studio is still preparing the item. |
| **Failed** | Studio could not prepare the item. |
| **Disabled** | An admin turned the item off. |
| **Superseded** | A newer item replaced it. |

### Filters

Search with **Search context...**. You can also filter by **Type**, **Status**, **Scope** and **Related Object Type**. The related object type is **Workspace**, **Mission** or **Agent**.

## Add an item

1. Select **+ Add Context Item**.
2. Enter a **Name**. If you leave it empty, Studio creates one.
3. Choose the **Type**.
4. Choose the **Scope**. For **Mission**, choose the **Mission**.
5. Give the content. The field depends on the type.
6. Add **Instructions** and **Tags** if you want. Separate tags with commas.
7. Save the item.

| Type | Content field |
| --- | --- |
| **Text** | **Content** |
| **File** | **File** |
| **URL** | **URL** and **Max crawl depth** |
| **Connection** | **Source identifier** |

The form also has a **Status** field. Set it to **Active** or **Disabled**.

## Read an item

Select an item to open its detail panel. The panel has these cards.

| Card | What it shows |
| --- | --- |
| **Properties** | Type, status, size, dates and reference. |
| **Content** | The content of the item. |
| **AI Data Preview** | How the context appears to AI agents. |
| **Attached To** | The object that owns the item. |

## Context of a mission

A mission page has its own **Context** section. It lists the items of that mission.

Mission managers can use these controls.

- **Add** opens the form with the mission already chosen.
- The edit and remove buttons on a row change or delete an item.
- Drop several files on the drop area, or click it, to add them as active file items.

Select the name of an item to open a read-only detail with a preview and a download. Everyone who can see the mission can do this.

:::tip[Check the preview]
Open **AI Data Preview** after you add an item. It shows what the agents receive.
:::
