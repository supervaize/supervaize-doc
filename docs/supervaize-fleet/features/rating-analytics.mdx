# Ratings and analytics

Users rate agents, missions, jobs and cases. Each rating uses **dimensions**. Studio also shows activity and cost charts on the Dashboard and on mission pages.

## Rating dimensions

A dimension is one question that a user answers, for example **Clarity** or **Execution Quality**. A dimension has an input type and a category.

| Input type | What the user gives |
| --- | --- |
| **Thumbs** | Thumbs up or thumbs down |
| **Stars** | 1 to 5 stars |
| **Score** | A score out of 10 |
| **Comment** | A comment only |

The category is **Operational performance** or **User interaction experience**.

Studio supplies 13 default dimensions. They are read-only and carry a **Default** badge. You can add your own.

## Set up ratings

A workspace admin opens **Settings**, then **Ratings Setup**. The page is titled **Ratings**.

The table lists each dimension with its **Type** and **Category**. It has one column for each object type that can be rated: agent, mission, job and case. A selected box means that the dimension applies to that object type.

| Control | What it does |
| --- | --- |
| **Add Dimension** | Opens a form with **Name**, **Description**, **Input Type** and **Category**. |
| **Edit** | Changes a custom dimension. |
| **Delete** | Removes a custom dimension after you confirm. |

### Default assignments

| Object | Default dimensions |
| --- | --- |
| Agents | All 13 default dimensions |
| Missions | All 13 default dimensions |
| Jobs | **Success** and **Final Thoughts** |
| Cases | **Success** and **Final Thoughts** |

## Turn on ratings for a mission

Rating is on or off for each mission. Open **Edit** on the mission. The **Ratings** group has three switches.

| Switch | Effect |
| --- | --- |
| **Rate this mission** | Users can rate the mission as a whole. |
| **Rate jobs** | Users can rate each job of the mission. |
| **Rate cases** | Users can rate each case of the mission. |

A switch turns on the default dimensions of that object type. You cannot turn on a switch when that object type has no default dimension.

## Give a rating

Open the page of the object. Each page has a rating control.

| Object | Control |
| --- | --- |
| Mission | **Mission Rating** button in the header |
| Job | **Job Rating** button in the header |
| Case | **Case Rating** button in the header |
| Agent | **Rating** card on the **Overview** tab |

The button tooltip reads **Rate this**. After you rate, it reads **You rated this — open to view or change**. The star turns amber.

## Analytics in Studio

| Where | What you see |
| --- | --- |
| Dashboard | Cards such as **Agent Activity** and **User Engagement**, with the cases of the last 7 days |
| Mission page | **Jobs** and **Cases** donut charts by status, **Mission Costs** and **Job Runs** |
| Mission, per agent | An **Insights** group with the links that the agent offers: **Overview**, **Analytics** and its own datasets |

The links in **Insights** show only when the agent declares them. Mission managers see them.

For the developer side, see [Job analytics](/docs/supervaizer-controller/job-analytics).
