# Create a mission

A mission groups the work of one or more agents around one goal: its jobs, its cases, its people and its costs. You create it once, then start as many jobs in it as you need.

- **Only the name is required.** Everything else can be filled in later.
- **Agents and people are attached to the mission.** They decide who can start jobs in it and who sees it.
- **You land on the mission page**, ready to start the first job.

## Create it in three steps

Try the flow here first. The buttons work.

<MissionCreateDemo />

### 1. Open the form

In the sidebar, open **Missions** and click **New Mission** at the top right.

:::info[You need the right to manage missions]
The **New Mission** button only shows for members who can manage missions. If you do not see it, ask a workspace admin.
:::

### 2. Fill in the form

| Field | What to enter | Default |
| --- | --- | --- |
| **Name** | The only required field | |
| **Description** | What the mission is for | Empty |
| **Status** | Draft, In Progress, Completed, On Hold or Cancelled | Draft |
| **Priority** | Low, Medium or High | Low |
| **Budget (USD)** | The amount you plan to spend | 0.00 |
| **Start Date / End Date** | The planned window | Empty |
| **Progress (%)** | A number from 0 to 100 that you set by hand | 0 |
| **Tags** | Type a tag, then press Enter or a comma | None |
| **Agents** | Search by name or slug and pick one or more | None |
| **Users** | Search by name or email and pick the teammates involved | None |
| **Default messaging channel** | Where the mission's messages go | No default channel |

:::tip[Add at least one agent]
A job always runs one agent of the mission. With no agent on the mission, there is nothing to start.
:::

### 3. Create

Click **Create Mission**. Studio opens the new mission's page. From there, [start a job](./job-management.mdx).

## Shortcut: create a mission from an agent

On an agent's page, **New Mission** opens a shorter, two-step dialog:

1. **Select Objective**: Debug, Experiment, Operate or Collaborate.
2. **Confirm Mission**: check the suggested name (for example _Mission to operate agent Aidan_) and keep or untick **Create Job**.

With **Create Job** ticked, Studio creates the mission and a first job for that agent, then opens the job. Unticked, it opens the mission.

## Find and edit missions

On the **Missions** page:

- **Search and filter** by status, agent or user.
- **Switch the layout** between **Card view** and **List view**.
- **Sort** by Name, Status, Created date or Updated date. The default is Updated date, newest first.

To change a mission, open it and choose **Edit**. The same form opens, plus rating switches for the mission, its jobs and its cases.

:::warning[Completing a mission with active jobs]
If you set the status to **Completed** while jobs are still running, Studio asks what to do: **Complete only** leaves those jobs running, **Complete and close jobs** closes them now.
:::

## Troubleshooting

| Symptom | Cause | Fix |
| --- | --- | --- |
| No **New Mission** button | Your role cannot manage missions | Ask a workspace admin |
| "Mission name is required." | The name is empty | Enter a name |
| An agent is missing from the **Agents** list | The agent is not available in this workspace | Add or share the agent first, see [Agent Management](./agent-management.mdx) |
| No **New Job** button on the mission | You are not allowed to run jobs in this mission | Ask the mission manager to add you |

## Vocabulary

| Term | Meaning |
| --- | --- |
| **Mission** | Groups the work of one or more agents |
| **Job** | One agent run inside a mission |
| **Case** | The agent's unit of work inside a job, for example one interview or one ticket |
| **Step** | One ordered event of a case; some steps wait for a human answer |
