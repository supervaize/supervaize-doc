This guide shows how to use Supervaize Studio. You register agents, group their work in missions, run jobs and follow the cases that the agents create.

## Platform Overview

Studio lets you:

- **Connect** AI agents and set their parameters
- **Create** missions that group jobs, cases and people
- **Run** jobs, once or on a schedule
- **Follow** cases and answer the agents that wait for a person
- **Check** agent work with rules
- **Rate** results and stay informed with notifications

Some features show only when they are enabled for your workspace. If a menu item is missing, ask a workspace admin.

## Core Features

### <i className="bi bi-1-circle"></i> [Agent Management](/docs/supervaize-fleet/features/agent-management)

Agents register themselves through a server. The **Agents** page lists them with a status: **Active**, **Inactive**, **Suspended**, **Error**, **Inaccessible** or **Paused**.

- Set secrets and parameters in the **Parameters** panel of an agent.
- An agent owner can pause an agent and resume it later.

### <i className="bi bi-2-circle"></i> [Mission Management](/docs/supervaize-fleet/features/mission-management)

A mission groups the jobs, cases, people and costs of one goal. Add agents and people to it, then start jobs.

### <i className="bi bi-3-circle"></i> [Job Management](/docs/supervaize-fleet/features/job-management)

A job is one run of one agent. Fill in the parameters of the agent, set limits and start.

- Some jobs start in testing mode, so you can try them before you go live.
- Mission managers can also start jobs on a schedule.

### <i className="bi bi-4-circle"></i> [Navigate a job](/docs/supervaize-fleet/features/job-navigation)

Follow the cases of a job as a board, a list or a calendar. Filter, sort and export them.

### <i className="bi bi-5-circle"></i> [Case Management](/docs/supervaize-fleet/features/case-management)

An agent creates cases inside a job. A case has steps, and some steps wait for a person.

- Open the **Actions Panel** to see the cases that need your input, the anomalies and the completed work.
- Add tags to jobs, cases and steps, and filter lists by tag.

### <i className="bi bi-6-circle"></i> [Context Management](/docs/supervaize-fleet/features/context-management)

Context items are files, text, URLs and connections. Workspace admins add them to the workspace. Mission managers add them to a mission.

### <i className="bi bi-7-circle"></i> [Rules](/docs/supervaize-fleet/rules/setup)

A rule is a check in plain language. Jev checks each agent step against it. A rule can warn, pause the job for approval, or stop it. See also [Run and review jobs with rules](/docs/supervaize-fleet/rules/run-and-review).

### <i className="bi bi-8-circle"></i> [Rating & Analytics](/docs/supervaize-fleet/features/rating-analytics)

Users rate agents, missions, jobs and cases with rating dimensions. Admins manage the dimensions in **Ratings Setup**. The **Dashboard** and the analytics of a mission show the activity and the costs.

### <i className="bi bi-9-circle"></i> [Notifications](/docs/supervaize-fleet/features/slack-notifications)

Connect Slack or email in **Integrations**. Set the events and the timing for each mission and agent. **My notifications** lists the notifications of all your workspaces.

## Workflow Overview

1. **Connect** the agents of your workspace.
2. **Create** a mission and add agents and people.
3. **Add context** to the mission, if the agents need it.
4. **Start** a job, or schedule it.
5. **Follow** the cases and answer the steps that wait for you.
6. **Rate** the results.

## Getting Started

1. **Check** the agents in the **Agents** page.
2. **Create** your first mission with the [Mission Management](/docs/supervaize-fleet/features/mission-management) guide.
3. **Start** a job with the [Job Management](/docs/supervaize-fleet/features/job-management) guide.
4. **Follow** its cases with [Navigate a job](/docs/supervaize-fleet/features/job-navigation).
