# The Skills Cookbook

The Skills Cookbook is the desktop application and the command line tool that manage skills for coding agents. Its documentation is at [skills.runwaize.com](https://skills.runwaize.com/getting-started).

The skills that Runwaize publishes for Supervaize are on the [Skills](/docs/integrations/skills) page:

- [Supervaizer Integration](/docs/integrations/skills/supervaizer-integration): a coding agent connects your Python agent to Supervaize Studio.
- [Supervaize Access](/docs/integrations/skills/supervaize-access): a chatbot or an IDE operates a Supervaize workspace.
