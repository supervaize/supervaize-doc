# Integrations with Third Party Applications

This section covers how to connect Supervaize with external tools and agents.

## Overview

| Area | What it does | Start here |
|------|----------------|------------|
| **[n8n Integration](/docs/integrations/n8n-integration)** | Use an n8n workflow as an Agent in Supervaize Studio. Run workflows as Jobs, pass inputs, track progress, and optionally use Human-in-the-Loop. | [n8n Integration](/docs/integrations/n8n-integration) |
| **[Skills](/docs/integrations/skills)** | Agent skills for the Runwaize ecosystem. Give your coding agent (Claude Code, Cursor, Codex, etc.) instructions to talk to Supervaize via REST, MCP, or the Supervaizer Controller. | [Skills](/docs/integrations/skills) |

## When to use which

- **You have an n8n workflow** and want it to run as a Supervaize Agent (e.g. from Missions or Jobs) → [n8n Integration](/docs/integrations/n8n-integration).
- **You have agent code** and want to instrument it with the Supervaizer Controller → [Supervaizer Integration](/docs/integrations/skills/supervaizer-integration).
- **Your workspace is live** and you want to manage agents, missions, and HITL from a chatbot or IDE → [Supervaize Access](/docs/integrations/skills/supervaize-access).
