# Bienvenue dans la documentation Runwaize {#welcome-to-runwaize-documentation}

Runwaize vous aide à exploiter des agents IA en production en toute confiance.

## Les deux composants {#the-two-parts}

- **Supervaizer Controller** est le SDK Python open source. Vous l'ajoutez à votre agent, et l'agent s'enregistre auprès d'un espace de travail Studio.
- **Supervaize Studio** est la plateforme où votre équipe exploite les agents : missions, jobs, cases, validations humaines, règles et analyses.

## Pour commencer {#getting-started}

Choisissez une section :

- [**Supervaizer Controller**](/docs/supervaizer-controller/quickstart) : installez le SDK, construisez votre contrôleur et déployez-le.
- [**Supervaize Studio**](/docs/category/supervaize-studio) : exploitez les agents, les missions et les jobs. Cette section couvre aussi les règles, les campagnes d'entretiens Aidan et le connecteur MCP.
- [**Intégrations**](/docs/integrations/intro) : les workflows n8n et les skills pour les agents de code.
