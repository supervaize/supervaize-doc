# The Skills Cookbook {#the-skills-cookbook}

The Skills Cookbook est l'application de bureau et l'outil en ligne de commande qui gèrent les skills des agents de code. Sa documentation se trouve sur [skills.runwaize.com](https://skills.runwaize.com/getting-started).

Les skills que Runwaize publie pour Supervaize sont sur la page [Skills](/docs/integrations/skills) :

- [Supervaizer Integration](/docs/integrations/skills/supervaizer-integration) : un agent de code connecte votre agent Python à Supervaize Studio.
- [Supervaize Access](/docs/integrations/skills/supervaize-access) : un chatbot ou un IDE pilote un espace de travail Supervaize.
